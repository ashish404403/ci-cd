# CI/CD Pipeline Examples

Sample CI/CD pipelines for common languages. Each uses GitHub Actions to build and push a Docker image to Docker Hub on every new release.

## Pipelines

| Language | Stack | Repo |
|----------|-------|------|
| Java | Spring Boot + Maven | [java-cicd](https://github.com/ashish404403/java-cicd) |
| Node.js | Express | [nodejs-cicd](https://github.com/ashish404403/nodejs-cicd) |
| PHP | Vanilla PHP | [php-cicd](https://github.com/ashish404403/php-cicd) |
| Python | Vanilla Python | [python-cicd](https://github.com/ashish404403/python-cicd) |
| Go | Vanilla Go | [go-cicd](https://github.com/ashish404403/go-cicd) |

Each repo is self-contained with its own `README.md` covering setup and pipeline details.
