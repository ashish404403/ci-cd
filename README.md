# CI/CD Pipeline Examples

This repository contains examples of CI/CD pipelines for various programming languages. Each pipeline is configured using GitHub Actions to automatically build and deploy a Docker image to Docker Hub when a new release is published.

## Pipelines

Below are the different application types with CI/CD pipelines in this repository. Each project is self-contained in its own repository and has a detailed `README.md` explaining its specific pipeline, setup, and how to run it.

### 1. Java CI/CD

A simple "Hello World" Spring Boot application. The pipeline builds the Java application using Maven and packages it into a Docker image.

➡️ [**View Java CI/CD repository**](https://github.com/ashish404403/java-cicd)

### 2. Node.js CI/CD

A basic "Hello, World!" Node.js application using Express. The pipeline builds a Docker image for the application.

➡️ [**View Node.js CI/CD repository**](https://github.com/ashish404403/nodejs-cicd)

### 3. PHP CI/CD

A "Hello World" PHP application. The pipeline is set up to create a Docker image for deployment.

➡️ [**View PHP CI/CD repository**](https://github.com/ashish404403/php-cicd)

### 4. Python CI/CD

A simple "Hello World" Python application. The associated GitHub Actions workflow builds and pushes a Docker image.

➡️ [**View Python CI/CD repository**](https://github.com/ashish404403/python-cicd)
